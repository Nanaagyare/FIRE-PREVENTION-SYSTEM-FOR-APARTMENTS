Fire Prevention System for Apartment

Project Overview

The Fire Prevention System for Apartments is a scalable smart apartment network designed and simulated using Cisco Packet Tracer and IoT devices.
 It detects smoke and potential fire hazards caused by LPG gas incidents 
 faulty electrical wiring, and human negligence, triggering automated responses to help protect lives and property.

Key Features

* Smoke Detection: Monitors smoke levels to identify potential fire hazards.
* Automatic Sprinklers: Activates water sprinklers during detected fire emergencies.
* Fire Alarm: Sounds a siren to alert occupants.
* Automatic Doors and Windows: Opens doors and windows to support emergency evacuation.
* Scalable Network: Supports an expandable apartment network using IoT technology.

 Technologies Used

* Cisco Packet Tracer
* Internet of Things (IoT)
* Network Simulation and Automation

 User Guide

Prerequisite: Basic computer knowledge.

Minimum System Requirements:

* Operating System: Windows 7 or later
* Hard Disk Space: 500 MB
* RAM: 1 GB
  Processor: Intel Pentium 4

How to Use:

1. Install Cisco Packet Tracer.
2. Clone or download this repository.
3. Open the `.pkt` project file in Cisco Packet Tracer.
4. Explore the network and test the automated fire response scenarios.

Project Objective

To improve apartment fire safety through early smoke detection and automated emergency responses, 
reducing reliance on manual intervention and helping minimise loss of life and property.

Note

This project is a simulation. Real-world deployment requires physical hardware implementation and safety testing.
